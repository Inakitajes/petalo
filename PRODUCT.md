# Product

## Status

Pre-1.0 UI foundation. The canonical product and repository name is **Petalo**.

## Purpose

Petalo is a small, native macOS surface attached to the MacBook notch or presented as a pill on external displays. It provides reusable UI structure, geometry, material, interaction, and display placement—not a prescribed data model or workflow.

## Design principles

- Preserve the physical-notch and external-display presentations.
- Keep the compact control quiet and the expanded canvas focused.
- Use familiar macOS materials, animations, and interactions.
- Keep product-specific state and integrations outside the UI foundation.
- Respect Reduce Motion and provide descriptive accessibility labels.
